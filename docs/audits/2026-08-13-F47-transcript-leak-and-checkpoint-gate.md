ошибкой, и Docker вернул строку подключения **с паролем** в тексте ошибки.
Новый вектор относительно Ф25: секрет утёк не печатью переменной, а текстом
ошибки внешней утилиты.

1. **Ротация** `rotate:stand-secrets` — утёкшее значение обесценено (11
   секретов стенда, `ALTER ROLE`, пересоздание контейнеров).
2. **Пак редакции** пересобран автоматически (46 правил, `gate:redactors` —
   «пак актуален»).
3. **Стенд восстановлен**: `minio-init`, сид тестовой учётки, перезапуск ядра.
4. **Новый гейт** `npm run gate:checkpoint-secrets`.
5. **Ветку на origin не трогал** — доказано, что утечки там нет.

## Ограничения и принятый риск

- В локальной shadow-ветке `entire/159ab01-e3b0c4` остаётся транскрипт со
  **старым, уже недействительным** паролем. Ветку не удалял: это чекпоинты
  текущей сессии (механизм восстановления). Риск принят — значение мёртвое,
  на origin ветка не уходила.
- Гейт не запускается в CI: там нет ни `.env`, ни веток `entire/*`. Это
  локальная проверка перед коммитом.
- Старых значений KEK у меня нет (ротированы ранее), поэтому «в истории нет
  старых KEK» доказано косвенно — отсутствием присвоений `KEK_*` с любым
  непустым значением, а не поиском конкретных строк.
