# SESSION AUDIT REPORT — Ф38: обнуление guardian.yml — расследование и защита

Дата: 2026-08-13. Четыре инцидента обнуления `.semgrep/guardian.yml` до 0 байт
(Ф4, Ф6, Ф8, Ф32); semgrep с пустым конфигом молча прогоняет 0 правил и
возвращает 0 — SAST-гейт зеленел, ничего не проверяя.

## Расследование (что доказано выводами инструментов этой сессии)

| Гипотеза | Вердикт | Доказательство |
|---|---|---|
| Скрипт/гейт репозитория пишет в файл | ИСКЛЮЧЕНО | grep по всем .mjs/.js/.yml/.ps1: все обращения — `--config` на чтение; записей в `.semgrep/` нет ни одной |
| Entire (hooks/чекпоинты) портит рабочее дерево | ИСКЛЮЧЕНО | лог Entire: только `checkpoint saved`, restore-операций нет; в истории всех git-ref'ов (включая shadow-ветки) ни одного коммита с пустым файлом |
| Git-механика (filters/checkout) | ИСКЛЮЧЕНО | фильтров нет; в истории файла один коммит создания |
| Внешний процесс сканирования на машине | ВЕРОЯТНО, не доказано | все 4 случая по времени совпадают с прогонами внешних инструментов (№4 — сразу после стороннего аудита 2026-08-13, запускавшего semgrep); USN-журнал NTFS недоступен без прав администратора |

Причинная цепь инцидента: внешний процесс открывает файл на запись с
truncate и не записывает содержимое → 0 байт в рабочем дереве → semgrep
`--config` пустого файла прогоняет 0 правил с кодом 0 → гейт зелёный впустую.

## Устранение

- **`attrib +R`** на файле: truncate внешним процессом теперь получает отказ
  ОС. Доказано вживую в этой сессии: попытка `: > guardian.yml` — `Permission
  denied` (ровно тот системный вызов, который обнулял файл).
- **`gate:sast-config`** (`scripts/check-sast-config.mjs`) — в общем `gate`,
  в CI и в `security-audit-full.mjs` ПЕРЕД SAST-прогоном: файл существует,
  байт в байт равен `HEAD:.semgrep/guardian.yml`, содержит ≥5 правил; mtime
  печатается всегда — следующий инцидент придёт с временной меткой; при
  успехе гейт сам восстанавливает read-only.

## Доказательства гейта

| Сценарий | Результат |
|---|---|
| Позитив | exit 0, «совпадает с HEAD, правил: 11», атрибут установлен |
| Файл обнулён | exit 1, «обнулён (пятый случай!)» + mtime |
| Файл расходится с HEAD | exit 1, «6485 байт против 6457» |
| Прямое обнуление при +R | отвергнуто ОС: Permission denied |
| ESLint / Prettier | 0 / чисто |

## Findings

| Severity | Что | Статус |
|---|---|---|
| MEDIUM | Причина обнуления — внешний процесс, точное имя не установлено (USN требует админа) | MITIGATED: повтор невозможен (+R) и мгновенно виден (гейт); при пятом инциденте будет mtime |
| MEDIUM | SAST мог зеленеть на пустом конфиге | FIXED: целостность проверяется до прогона |

## Ограничения

- Имя процесса-виновника не названо: это потребовало бы аудита ОС с правами
  администратора (SACL/USN). Защита сделана так, что имя перестало быть
  необходимым для безопасности, а при повторе станет устанавливаемым.
- Правка правил semgrep теперь требует `attrib -R` перед редактированием —
  гейт напоминает об этом в сообщении.
