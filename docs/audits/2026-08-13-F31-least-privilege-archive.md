## 4. Ограничения

- **SSE-KMS и Object Lock** для объектов архива — свойства production-хранилища,
  локально не подменяются и не имитируются.
- Учётка `unicorn_archive` может ПЕРЕЗАПИСАТЬ объект под `archive/*` (PutObject
  разрешён — он же нужен для выгрузки). От перезаписи защищает версионирование
  бакета (Ф29) и сверка содержимого при каждом прогоне; неизменяемость до
  истечения срока даёт только Object Lock в production.
- Правка checksum в журнале миграций — ручное вмешательство; применена ровно к
  одной строке и задокументирована здесь и в грaблях.
