## 4. Ограничения

- Живая часть гейта работает только при доступной БД (в CI — статическая
  часть, это сказано в самом CI-шаге).
- Гейт статически разбирает исходники регулярными выражениями: вызов
  `seal(variable, …)` с доменом-переменной он не увидит. Сейчас все вызовы
  литеральные; появление переменной домена потребует доработки гейта.

## 5. Техдолг

- Закрыт: ручная карта ротации без сверки; вопрос о трёх доменах.
- Без изменений: перешифровка `webhook_secrets` и пересчёт blind index при
  ротации `search_index` — по-прежнему пишутся при первой необходимости.

## 6. Рекомендации

- При включении шифрования любого зарезервированного домена: убрать колонку из
  RESERVED_DEK_COLUMNS, домен из RESERVED, внести запись в ENVELOPE — гейт
  проведёт по всем трём шагам своими падениями.
