## 4. Аудит §3.1 — прикладная безопасность

- **Выдача роли себе отклоняется** — проверено рендером: сервер отвечает
  отказом, кабинет показывает его текст.
- **Журнал:** выдача роли другому пользователю даёт ровно одну запись
  `identity.role.granted` (проверено запросом в БД после действия в браузере).
- **Секрет клиента Integration API** показывается один раз и сопровождается
  объяснением, почему повторно его увидеть нельзя (в базе только Argon2id-хеш).
- **Прав на клиенте не проверяется:** админка показывает предупреждение при
  отсутствии роли `admin`, но все операции всё равно отклоняет сервер.
- **Зависимости:** новых пакетов не добавлено.
