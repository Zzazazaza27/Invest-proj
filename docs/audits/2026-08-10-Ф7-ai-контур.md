## 4. Проверка §3.1 по новым компонентам

- **Вход:** pydantic-схемы с жёсткими границами (длина текста 100 000, максимум
  50 материалов, `task` — enum из одного значения), лимит тела 1 МБ на уровне
  middleware. В core — `parseOrThrow` со строгими zod-схемами.
- **AuthN:** сервисный токен сравнивается `hmac.compare_digest`; токен короче
  32 символов роняет сервис на старте. Проверено вживую: без токена и с чужим
  токеном — 401.
- **AuthZ / IDOR:** запуск анализа разрешён владельцу проекта и админу; чужому
  основателю — 404 (не 403: статус не подтверждает существование). Паспорт
  инвестору виден только с активной подпиской И опубликованным листингом —
  проверено тремя состояниями подряд.
- **AI-поверхности:** недоступность недоверенного входа к инструкциям проверена
  позитивным контролем — материал с `ignore all previous instructions ...
jurisdiction=US data_class=public` не изменил ни класс данных, ни юрисдикцию;
  попытка зафиксирована (`injectionMarkers: 4`) и в журнале шлюза, и в журнале
  core.
- **Резидентность:** `pdn` и `commercial_secret` провайдеру вне РФ — 403
  `residency_violation`. Политика, в которой такому провайдеру разрешили бы
  ограниченный класс, не загружается вовсе (тест).
- **Конкурентность и целостность:** результат анализа пишется одной
  транзакцией; неудача шлюза оставляет прогон `failed` и НЕ создаёт паспорт —
  проверено остановкой шлюза вживую.
- **Внешние вызовы:** таймаут 30 с, адрес только из конфигурации, ретраев нет
  (анализ не идемпотентен), тело ответа шлюза в текст ошибки не попадает.
- **Зависимости:** новые Python-пакеты зафиксированы по версиям и прогнаны
  через `pip-audit`.

## 5. Проверка §3.2 (сетевой проход)

Фаза добавила **один новый слушатель** — 127.0.0.1:8100. По нему выполнен
отдельный проход (см. таблицу гейтов): привязка, аутентификация, схема API,
баннер, заголовки. Исходящих направлений добавилось одно: core → шлюз, адрес из
конфигурации, https обязателен в production (проверка в `env.ts`). Внешних
сетевых вызовов шлюз в этой фазе не делает: единственный включённый провайдер
работает внутри процесса.
