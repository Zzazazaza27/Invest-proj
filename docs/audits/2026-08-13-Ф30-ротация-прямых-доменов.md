## 4. Ограничения

- Пересчёт blind index читает открытые значения контактов в памяти процесса
  ротации — неизбежно для HMAC; буферы зануляются после использования, значения
  не печатаются и не пишутся никуда, кроме HMAC.
- Уникальные индексы по hmac-колонкам не пересоздавались: пересчёт — биекция
  на тех же строках, конфликтов быть не может (и БД бы их отвергла).
