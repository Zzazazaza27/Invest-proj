## 4. Ограничения

- Правка тестовой БД (перенос 3200 строк) выполнена SQL-командой вне миграции:
  файл M051 уже применён к основной БД, а журнал сверяет checksum — менять его
  задним числом нельзя. Для свежих БД (CI) M051 самодостаточна: пустая таблица
  проходит ассерт.
- `-- migrate:contract` не проверяет фактическую выкатанность expand-фазы —
  это ответственность автора миграции, о чём WARN и напоминает.
