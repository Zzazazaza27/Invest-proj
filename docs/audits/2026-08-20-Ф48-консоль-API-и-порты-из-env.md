### Про `publication-consents` (OPEN)

Подтверждено фактом: вызов из консоли против живого ядра — **HTTP 404**.
Метод `api.publication.grant/revoke` в `packages/api-client` есть, маршрута в
`apps/core` нет (`grep` по контроллерам — ноль совпадений). Это ровно тот класс
расхождения, который ловится только вызовом против живого сервера. Решение —
за владельцем: реализовать маршрут или убрать метод из клиента. Операция
оставлена в консоли с пометкой в описании, чтобы расхождение оставалось видимым.

## Что показал сквозной прогон

Пройдено браузером через саму консоль, против живого ядра:

1. `health` 200 → справочник направлений 200, `taxonomyId` записан в блокнот;
2. вход основателем, роль показана в шапке;
3. создание проекта 200, `projectId` в блокноте;
4. **идентификатор подставился в следующую операцию сам** — карточка проекта
   получена без ручного переноса UUID;
5. ссылка `https://example.com` принята; `https://127.0.0.1/admin` отвергнута
   **400 validation_failed** — защита от SSRF работает;
6. подача заявки: сначала **409 state_transition_not_allowed** (сезона в приёме
   не было), после починки сида — 200 и версия-снимок в истории;
7. очередь комплаенса основателю — **403 forbidden**;
8. выход 200, после него «кто я» — **401**.

## Ограничения и принятый риск

- **Пароль стенда в транскрипте этой сессии.** До правки `dev-stand` успел
  напечатать значение `DEV_TEST_USER_PASSWORD`. В ветки чекпоинтов оно не
  попало (`gate:checkpoint-secrets` — exit 0: пак редакции его вырезает), но в
  выводе терминала оно есть. Рекомендация владельцу: `npm run rotate:stand-secrets`.
  Не выполнено без спроса — операция необратимая.
- **Инвестиционный контур сквозным прогоном не проверен.** Он требует
  проверенного юрлица (KYB) и второго фактора (step-up MFA), которого локальный
  адаптер не выдаёт. Операции в консоли есть, но их фактический прогон здесь не
  делался — заявлять их работоспособность нельзя.
- **Загрузка файла материала из браузера не проверена.** Операция реализована по
  контракту (POST-форма с `formFields`, файл последним полем), но фактически не
  запускалась: политика CORS хранилища для записи из браузера не проверялась.
- Прогоны шли под одним общим сезоном стенда; изоляция между прогонами
  не вводилась.
- Продуктовые кабинеты не дорабатывались — покрытие API интерфейсом выросло за
  счёт консоли, а не за счёт `lab`/`investor`/`expert`.
