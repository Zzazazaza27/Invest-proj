### Разбор HIGH

**1. Клиент, который никто не вызывал.** `@unicorn/api-client` существует, чтобы
расхождение сервера с контрактом обнаруживалось сразу. Проверены три гипотезы о
причине пустого экрана: (а) сервер не отвечает — опровергнута прямым запросом
(HTTP 200 с данными); (б) CORS — подтверждена частично и исправлена отдельно;
(в) клиент не разбирает ответ — **подтверждена**: сервер отдаёт `{"season":{…}}`,
клиент парсил `SeasonSchema`. Проверка до/после: было — «активного сезона нет»
при открытом сезоне; стало — «Приём заявок открыт, Сезон 7» на скриншоте.
Класс дефектов закрыт прогоном, который вызывает каждый публичный метод против
живого API.

**2. Выдуманные данные на витрине.** Прежний макет содержал шесть «проектов» с
суммами и статусами. Для публичной страницы инвестиционной платформы это не
плейсхолдер, а введение в заблуждение. Удалено вместе с файлами макета; в
рендер-проверке закреплена проверка, что этих названий на странице нет.

## 4. Аудит §3.1 — прикладная безопасность

- **Витрина анонимна by design:** клиент создан с `auth: { kind: 'none' }`.
  Ни сессии, ни токена в этом приложении нет — появление их означало бы, что
  публичная страница начала показывать чужие данные.
- **Граница фронт↔бэк:** проверена гейтом (10/10). Фронтенд импортирует только
  `contracts`, `api-client` и `ui`; прямого доступа к БД, очередям и хранилищу
  нет и быть не может.
- **Вывод данных:** все значения приходят из API и рендерятся React'ом
  (экранирование по умолчанию). `dangerouslySetInnerHTML` в приложении нет.
- **Ошибки наружу:** пользователю показывается `detail` из problem+json и
  `traceId`; технические детали (стек, тип исключения) на страницу не попадают —
  проверено рендером при оборванной сети.
- **Таймаут:** 10 секунд на запрос; прерывание зависшего запроса проверено
  детерминированной подменой транспорта.
- **Зависимости:** добавлен `playwright@1.62.1` (devDependency, версия
  закреплена), `npm audit` чист.

## 5. Аудит §3.2 — сетевая безопасность

Прогон `scripts/network-audit.mjs`: 13 проверок, 0 находок.

Фаза изменила ровно один элемент периметра — **allowlist CORS**: добавлены
`http://127.0.0.1:<порт>` рядом с `http://localhost:<порт>` для пяти портов
фронтендов. Это dev-конфигурация; отражения произвольного `Origin` и `*` нет —
проверено гейтом (`cors` и `cors-live`: чужой Origin не получает
`Access-Control-Allow-Origin`). Портов фаза не открывала: витрина обслуживается
vite-preview на loopback и в production собирается в статику.
