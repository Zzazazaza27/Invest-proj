## Ограничения (честно)

- **Стенд:** поток «сохранить → проверить → отозвать» для OpenAI пройден живьём после M068: 200 (отпечаток), `provider_auth` от api.openai.com на тестовый ключ, отзыв → пустой список.
- **Живой провайдер DeepSeek (`deepseek-v4-flash`) подключён на стенде 2026-08-26**: eval-гейт 13/13 (см. «Гейты»), флаг включён, переанализ 108 проектов выполнен 2026-08-27 (`scripts/reanalyze-projects.mjs`: 106/106 без ошибок, ещё 2 — в пробных прогонах). Паспорт проверен через API: `modelVersion llm:deepseek:deepseek-v4-flash:v2.5.1`, 9 осей, балл 7/10, verdict по-русски.
- **Ранее:** живой LLM-провайдер не вызывался. Ключей у владельца в этой сессии нет;
  путь модели проверен тестами с подменой сети (`test_llm.py`) и eval-гейтом
  на эвристике. Первый живой вызов — после ввода ключа в панели: «Проверить»
  → `node scripts/eval-ai-scoring.mjs` → флаг.
- GigaChat требует обмена client secret на access token — адаптер ждёт
  готовый токен в поле ключа; обмен не реализован.
- Перевод тестировался только с подменой; с живой моделью нужен прогон Э8
  «два читателя — одинаковые числа, разный текст».
- Статический аудит не заменяет pen-test и runtime-анализ.

  CHECK продуктов миграцией и `PRODUCT_VERTICALS` в панели.
