# ADR-001 — Модульный монолит с событийным ядром

- **Статус:** принято
- **Дата:** 2026-08-10
- **Основание:** `docs/architecture/Architect.md` §3.1, `docs/architecture/Architect_Launch.md` §2, §3

## Контекст

Launch — регулируемый оператор инвестиционной платформы. Договор инвестирования,
подтверждение первого транша и однократное начисление вознаграждения ОИП должны
происходить **в одной транзакции БД**: расщепление этого инварианта по сетевым
границам превращает его в распределённую сагу с компенсациями на денежном
контуре. Команда — не более 12 инженеров.

## Решение

Один деплоймент `apps/core` (NestJS, TypeScript strict) с явными доменными
модулями. Границы доменов = доменные схемы PostgreSQL (`identity`, `kyc`, `lab`,
`investments`, `scoring`, `experts`, `seasons`, `comms`, `billing`, `audit`,
`integration`). Взаимодействие с будущими платформами (Unicorn Capital,
медиаконтур Шоу) — только через Integration API и события NATS JetStream,
никогда прямым доступом к БД.

Каждая внешне наблюдаемая доменная мутация и запись в `audit.outbox_events`
коммитятся одной транзакцией (transactional outbox). Релей публикует в NATS,
консьюмеры идемпотентны по `event_id`.

## Последствия

**Плюсы**

- Транзакционная целостность денежного и регулируемого контура без саг.
- Один стек, одна миграционная линия, один набор гейтов.
- Вынос домена в отдельный сервис возможен позже по триггеру нагрузки.

**Минусы и честные ограничения**

- Межсхемные FK допустимы сейчас, но при выносе домена в отдельный сервис их
  придётся заменить локальными проекциями и контрактами. «Вынос без изменений»
  не обещается — это прямо зафиксировано в `docs/architecture/Architect_Launch.md` §2.4.
- Общий деплоймент = общий blast radius при аварии рантайма. Митигируется
  раздельными пулами БД по ролям, rate-limit по классам и graceful shutdown.

## Проверка

- `npm run lint` — правило `no-restricted-imports` запрещает импорт бэкенда во
  фронтенд и наоборот.
- Тест архитектуры в CI: доменная мутация без зарегистрированного outbox-события
  роняет сборку.
