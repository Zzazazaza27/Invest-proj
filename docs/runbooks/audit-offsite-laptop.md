# Вынос выгрузки аудита на ноутбук Томаса — установка задания (2.1.5)

Последнее отдельное согласование с Томасом по расписанию (Тэнк, 09.11.2026). Пока задание
не работает, пакет 2.1.5 целиком не закрыт.

## Что устанавливается

Задание планировщика Windows **«5E audit offsite»** от учётной записи Томаса, без
повышенных прав:

- запуск раз в сутки в 13:20, без окна консоли (до выхода в прод; затем ежечасно); пропущенный — при первой
  возможности; только при сети; не дольше 30 минут; второй экземпляр не запускается;
- команда `node scripts/audit-offsite.mjs pull` в `D:\Programming\fifth-element`;
- по SSH ключом `~/.ssh/maus_5e` читает порции через `fifth-backup-read` (только чтение) и
  ставит на сервере отметку выноса.

Порция принимается, только если подпись описи верна закреплённым ключом
(`infra/audit/export-signing.pub`, SHA-256 начинается с `b56503f3700f16b3`) и опись
продолжает контрольную точку. Файлы остаются зашифрованными на ключ Томаса.

## Куда сохраняются обе серии

```
D:\cloud@mail.ru\projects\5E\audit-export\
  prod\series\NNNNNN.jsonl.gpg | .manifest.json | .manifest.sig
  prod\checkpoint.json
  test-2\series\…
  test-2\checkpoint.json
```

`checkpoint.json` — доверенная контрольная точка получателя. При восстановлении её
передают применению (`--checkpoint`). Удалять или переносить без серии нельзя.

## Установка

```powershell
powershell -ExecutionPolicy Bypass -File infra\laptop\install-audit-offsite.ps1
```

Скрипт проверяет ключ выгрузки и ключ SSH, ставит задание и сразу запускает первый вынос.

## Проверка первого выноса

```bash
node scripts/audit-offsite.mjs check
```

Ожидается по каждой среде:

- «серия с начала проверена, порций N»;
- «контрольная точка совпадает с концом серии»;
- «покрыто до … (≤ 72 ч)»; до выхода в прод порог 72 ч, затем 3 ч;

и по заданию — «расписание: последний запуск …, результат 0».

На сервере сигналы `audit-offsite-prod` и `audit-offsite-test-2` в проверке копий
становятся «ok» при следующем проходе проверки (до 15 минут).

## Снять

```powershell
Unregister-ScheduledTask -TaskName "5E audit offsite" -Confirm:$false
```

Серии и контрольные точки при этом остаются.
