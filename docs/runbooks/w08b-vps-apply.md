## Состав выпуска

Коммит `main` с зелёным CI (SHA — в отчёте). Архиватор на Garage: «версия»
объекта — SHA-256 байтов; квитанции, граница, файлы почты, пакеты и пробелы
подписаны MAC и связаны в цепочку; эталон — голова цепочки (контрольный хеш
и число звеньев) в `chain.json` и в описи копии на ноутбуке. Остальное — как
готовилось раньше: юниты `fifth-logs-*`, лимиты journald, драйвер journald
дополнением compose (теперь и для узлов Garage), журнал запросов Caddy,
`secrets-draft`, проверка ключа из комплекта (`--bundle`).

## После применения

- Локальная история (journald, журналы остановленных контейнеров) не
  очищается — отдельным решением после копии.
- `fifth-dns-primary` (свой compose) — на json-file, TODO сейфа.
- Ручные команды compose — только `node scripts/infra.mjs compose …`.
- Защита архива на Garage — обнаружение, не запрет: ключ записи может
  перезаписать и удалить; копия на ноутбуке защищает только скачанное.

## Возврат

| Что                | Как                                                                          |
| ------------------ | ---------------------------------------------------------------------------- |
| Код                | откат выкладки                                                               |
| Архив              | `systemctl disable --now fifth-logs-{run,files,pack}.timer`; бакеты остаются |
| journald           | удалить `50-fifth.conf`, перезапуск                                          |
| Драйвер контейнера | убрать `DOCKER_LOG_DRIVER`, `infra.mjs compose up -d --no-deps <сервис>`     |
| Caddy              | вернуть копию Caddyfile, reload                                              |

Журналы json-file, удалённые пересозданием в шаге 7, не возвращаются —
пересоздание только после «покрыт целиком».
