# Выпуск W08a на VPS — план (на согласование Томаса)

Подготовлен 2026-11-02. Включение — только после «да» Томаса на этот план.
Общий порядок команд — `docs/runbooks/monitoring.md`, «Включение на VPS». Здесь —
конкретная последовательность для текущего состояния сервера, проверки после
каждого шага и откат.

## Состояние VPS (чтение 2026-11-02)

- Код: `f5757ad` (2026-11-01). С него в коде 11 коммитов W08a и DNS.
- Миграции: до M151. Будут применены **M152–M156**:
  - M152 — `audit.queue_metrics` (метрики очередей);
  - M153 — `audit.control_objects` + `audit.control_object()`;
  - M154 — источник учётной записи `monitoring`;
  - M155 — функции признаков служебной учётки;
  - M156 — RLS для `control_objects`.

  Все пять только добавляют объекты, существующие данные не меняют.

- Zabbix не поднят. Из таймеров есть только `fifth-backup-*`.
- Память: свободно ~7 ГБ из 8 ГБ. Zabbix по замеру на стенде занимает
  ~110 МБ, пределы — 512 + 256 + 128 МБ. Диск: свободно 103 ГБ. Подкачка не
  нужна.
- DNS Beget лежит — проверки по имени временно заменяются проверками по IP
  (`curl --resolve 5espace.com:443:193.233.217.210`).

## Откат

- **Наблюдение (шаги 3–10):**
  - `systemctl disable --now fifth-monitor-*.timer`;
  - остановить и удалить контейнеры Zabbix;
  - убрать `MONITOR_PULSE_PUBLIC_DIR` и пересоздать `web`;
  - удалить переменную `FIVE_E_PULSE_URL`.

  База `zabbix` остаётся. Удалять её или нет — решение Томаса.

- **Код (шаг 1):** выкладка прежнего `f5757ad`. Миграции forward-only:
  M152–M156 остаются, прежний код их не использует.
  **Важно:** в прежнем коде нет ограничения служебной учётки мониторинга
  (M155 и проверка в ядре). При откате кода после шага 4 учётку нужно
  **заблокировать до отката** — иначе у неё права обычного участника.
- **Критерий отката кода:** сайт или вход не работают после шага 1 и
  причина не устраняется за 15 минут.

## Что не входит

- Healthchecks.io — не используется. Вместо него пульс читает внешняя
  проверка (шаг 9). Регистрацию можно повторить позже как второй пульс.
- DNS: схема скрытого первичного — отдельный план. Выпуск W08a от DNS не
  зависит.
- Подкачка — не нужна при текущей памяти.
