# Журнал изменений продукта — по этапам

Что добавлено, изменено, отключено или откачено; какие прежние правила
перестали действовать; какие миграции и настройки нужны; как проверить.
Ведётся по этапам `план-этапов-заявки.md`; запись делается **в том же
этапе**, где меняется поведение (план 0.2 §13). Текущее состояние —
`руководство-по-продукту.md`; инженерные фазы — `CHANGELOG.md`.

Порядок записей — новые сверху. Шаблон записи — в конце файла.

  стадии зрелости проекта.
