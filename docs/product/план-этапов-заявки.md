# План этапов: инвестиционная заявка «Пятый элемент»

Составлен 2026-09-14 по постановке v3 (§25 «Последовательность имплементации»)
ДО исследовательского прохода. Этап 0 этот план уточняет: состав коммитов
внутри этапов 2–7 — ориентир, а не обязательство. Порядок этапов и границы
между ними — обязательство: следующий этап не начинается, пока предыдущий не
проходит свои проверки.

Правила, как и раньше: работа в `main`, один осмысленный кусок — один коммит,
перед коммитом гейты (`format:check`, `lint`, `typecheck`, тесты ядра,
`smoke:techdebt`), форматирование отдельными коммитами, запись в `CHANGELOG.md`
по закрытии этапа, выкат на стенд — только по слову владельца, с тегом.

Нумерация фаз в `CHANGELOG.md` продолжается с Ф70.
