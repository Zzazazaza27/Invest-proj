# Продуктовые документы

Что должен видеть и уметь пользователь. Здесь нет ни кода, ни архитектуры —
только сценарии и то, что из них следует.

Каталог рассчитан на чтение без git: версии документов и история изменений
записаны прямо в файлах, а этот список говорит, какой файл сейчас актуален.

## С чего начать

**Проходить стенд** — `чек-лист-сценариев.md`. Садишься, идёшь по шагам,
отмечаешь галочки, пишешь замечания в строке. Учётные записи и адреса
перечислены в шапке файла.

**Понять замысел** — `пользовательские-сценарии.md`. Версия 1 отвечает на
вопрос «зачем», версия 2 — на вопрос «как». Первая не устарела, а объясняет
вторую.

**Проверить полноту** — `карта-покрытия-сценариев.md`. Из неё взяты сценарии
11–15: логика вынута из кода (статусная машина, статусы листинга, роли,
переключатели функций) и наложена на сценарии, после чего стало видно, что
ветка отказа и середина воронки не проходятся ничем.

## Правило, общее для всех документов

> **где я → что сейчас происходит → что я могу и должен сделать дальше**

Если на экране нет ответа хотя бы на один вопрос — это задача для разработки,
а не мелочь.

## Как вести версии

Существенно изменил документ — подними номер версии в его шапке, допиши строку
в таблицу «История версий» внутри файла и поправь эту страницу. Правки
формулировок версию не поднимают.

Предыдущие версии не удаляются: они объясняют, откуда взялась текущая. Находки
прохождения идут в `TODO.md` в корне репозитория.
