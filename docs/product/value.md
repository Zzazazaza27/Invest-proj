# Ценность платформы — формулировки по аудиториям

Готовые формулировки для писем, презентаций и лендинга. Каждая ссылается на
идею или функционал, откуда пришла (`docs/product/ideas/`). Пополняется, когда
в работе находится новая ценность — для нового или уже существующего
функционала.

## Акселератору / партнёру

- Постоянная инвестиционная витрина выпускников вместо одноразового Demo Day.
  → [идея 001](ideas/001-accelerator-cabinet.md)
- Продолжение поиска инвестиций после окончания программы.
  → [идея 001](ideas/001-accelerator-cabinet.md)
- Результаты выпускников после программы — статистика и кейсы для следующего
  набора. → [идея 001](ideas/001-accelerator-cabinet.md)
- Обратная связь от рынка инвесторов, а не от методологов.
  → [идея 001](ideas/001-accelerator-cabinet.md)
- Меньше ручной упаковки: профиль проекта — основа всех материалов.
  → [идея 001](ideas/001-accelerator-cabinet.md)
