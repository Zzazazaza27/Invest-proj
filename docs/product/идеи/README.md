# Банк идей и ценности

Здесь живёт то, что НЕ является задачей: продуктовые гипотезы, направления
развития и найденная ценность для уже существующего функционала. TODO — список
того, что надо сделать; сюда — то, что стоит помнить, использовать в материалах
и учитывать при проектировании.

## Как устроено

- **Одна идея — один файл** `NNN-короткое-имя.md`. Шапка обязательна:

  ```
  Статус: гипотеза | принята | отклонена | реализована
  Источник: Томас | Тэнк | Маус | находка в работе (что за работа)
  Дата: ГГГГ-ММ-ДД
  Связано: роли, разделы, таблицы, документы
  Архитектурно не закрывать: что должно остаться возможным (если есть)
  ```

  Дальше — сама идея (текст источника без пересказа), ценность по аудиториям
  и блок **«Для материалов»**: готовые формулировки для писем, презентаций,
  лендинга — с пометкой, для кого.

- **`ценность.md`** в `docs/product/` — сводная библиотека формулировок по
  аудиториям (акселератор, инвестор, основатель…). Каждая строка ссылается на
  файл идеи, откуда пришла. Отсюда берут текст для рассылки или слайда.

- **В TODO** — только строка-указатель, если идея требует чего-то от текущей
  разработки (например, «не закрыть архитектурно»). Сама идея туда не
  переносится.

- **Статус меняет владелец.** Гипотеза не становится задачей без отдельного
  решения.
