## Правила

- **Исследуем под вопросы**, а не «весь функционал». Наблюдение, которое не
  отвечает ни на один вопрос ниже, — в раздел «Прочее» своей площадки одной
  строкой, не больше.
- **Уровень достоверности у каждого утверждения:** `видел в продукте` (свой
  вход, демо, скриншоты кабинета) · `документация` (справка, API, оферта,
  правила) · `витрина` (лендинг, маркетинг, СМИ) — предположение.
- **Учётные записи на площадках ассистенты не создают.** Где функционал за
  входом — пометка «нужен вход владельца», Томас решает, регистрироваться ли.
- **Ограничение по времени — одна рабочая сессия на исполнителя.** Не
  укладывается — сказать сразу, до продолжения.
- Каждый пишет **только в свою папку** (`маус/`, `тэнк/`) — ветки сливаются в
  main без конфликтов. Общую сводку (`сводка.md`) пишем после слияния обеих.

## Формат результата

Каждый исполнитель в своей папке:

- `площадки/<имя>.md` — по шаблону ниже;
- `итог.md` — таблица «площадка × В1–В9» (коротко, с уровнем достоверности)
  и по каждому вопросу вывод: **берём / не берём / делаем иначе** и что это
  меняет в профили-01;
- новые продуктовые идеи — сразу в `docs/product/ideas/` по правилам банка;
- то, что требует работы в следующих этапах, — строкой в TODO, раздел
  «Этап 9 — профили и организации».
