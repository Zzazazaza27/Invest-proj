## 4. Как переносим (после подтверждения)

Явно, **без `--mirror` и без `--force`**:

1. Создать **пустой** приватный репозиторий (без README, лицензии, шаблонов).
2. `git remote add stage2 <адрес нового>`
3. `git push stage2 main` и `git push stage2 pre-stage-2 stand-2026-09-02 stand-2026-09-13 stand-2026-09-28`
4. Проверить: `git ls-remote stage2` — те же хэши, что локально; полный
   ручной запуск CI на новом `main`; секрет-скан на всей истории (он идёт на
   каждый push, `fetch-depth: 0`).

Перед отправкой — **решение о двух мелких локальных коммитах** `b59cc58`
(форматирование) и `925d749` (выключение Entire): оставить как есть (честная
история) или слить `b59cc58` в `4a927f5` ради «чистой» формы
`7416605 → 4a927f5 → …`. Они ещё нигде не опубликованы, поэтому слияние
технически безвредно, но хэш `4a927f5` изменится. По умолчанию — **оставить**.
