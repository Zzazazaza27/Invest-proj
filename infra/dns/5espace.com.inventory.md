# Опись зоны 5espace.com

Составлена 2026-11-02, во время отказа DNS Beget (инцидент
`docs/incidents/2026-11-02-beget-dns.md`). Самой зоны в Beget сейчас не
видно, и она может вернуться из резервной копии не целиком. Здесь — то, что
известно с нашей стороны: VPS, Caddy, HestiaCP. После восстановления NS у
Beget каждую запись сверить запросом к их NS. Расхождения — в этот файл, а
затем в `infra/dns/zones/5espace.com.zone` для схемы со скрытым первичным.

## Известно с нашей стороны

| Имя               | Тип         | Значение                         | Откуда известно                                                 |
| ----------------- | ----------- | -------------------------------- | --------------------------------------------------------------- |
| `5espace.com`     | A           | 193.233.217.210                  | Caddy `5espace.com`, внешняя проверка по IP                     |
| `www`             | A или CNAME | 193.233.217.210 / `5espace.com.` | Caddy `www.5espace.com` (переадресация на основной)             |
| `files`           | A           | 193.233.217.210                  | W06, внешняя проверка (GET `/` → 404 по контракту)              |
| `panel`           | A           | 193.233.217.210                  | Caddy `panel.5espace.com` (HestiaCP)                            |
| `mail`            | A           | 193.233.217.210                  | Caddy `mail.5espace.com`; PTR `mail.5espace.com` у aeza         |
| `mail._domainkey` | TXT         | `v=DKIM1; k=rsa; p=…`            | HestiaCP: `v-list-mail-domain-dkim-dns admin 5espace.com plain` |

## Сверить с Beget после восстановления — значения неизвестны

| Имя              | Тип       | Что известно                                                                  |
| ---------------- | --------- | ----------------------------------------------------------------------------- |
| `5espace.com`    | MX        | входящая почта — у Beget (память: «DNS и входящая почта — в Beget»)           |
| `5espace.com`    | TXT (SPF) | отправка — exim на VPS (193.233.217.210); в SPF должны быть VPS и почта Beget |
| `_dmarc`         | TXT       | неизвестно                                                                    |
| прочие TXT       | TXT       | подтверждения сервисов, если есть                                             |
| CAA              | CAA       | неизвестно; Caddy получает сертификаты Let's Encrypt                          |
| TTL всех записей | —         | неизвестно                                                                    |

## Проверка после восстановления

Запросы — напрямую к каждому NS Beget, с VPS: со своей машины исходящие на
порт 53 режутся. Например:

```
docker run --rm --network host cznic/knot:3.4 kdig @ns1.beget.com 5espace.com ANY
```
