# Статус фаз

Ведётся после каждой фазы. Правило: ✅ ставится **только** после наблюдаемого
вывода инструмента в той же сессии.

## Ф0 — Фундамент ✅ 2026-08-10

**Сделано**

- Монорепо на npm workspaces: `apps/*`, `packages/*`, `database`, `e2e`.
- TypeScript strict (`tsconfig.base.json`), ESLint 9 flat config, Prettier.
- **Граница фронт↔бэк формализована как правило линтера**, а не соглашение:
  `no-restricted-imports` + SAST-правило `unicorn-frontend-must-not-touch-db`.
- `infra/docker-compose.yml`: PostgreSQL 16 (свой образ), Redis 7.4, NATS 2.10
  JetStream, MinIO, Keycloak 26 (профиль `idp`), Mailpit. Все порты — только
  на `127.0.0.1`.
- CI (`.github/workflows/ci.yml`): 7 гейтов — линт/типы/формат, gitleaks, semgrep
  (OWASP + свои правила), npm audit + pip-audit, миграции+RLS на реальном PG16,
  юнит-тесты, сборка.
- ADR-001…005, руководство по замене фронтенда, README, TODO.

**Не проверялось (честно)**

- CI-воркфлоу целиком — прогон будет при первом push в GitHub.
- Keycloak не поднимался: профиль `idp` включается в Ф3.
- `gitleaks` локально не установлен — секрет-скан только в CI.
- Живая проверка заголовков/CORS/cookie/rate-limit — core появится в Ф3;
  гейт честно вернул `LOW live-api`, а не зелёный статус.
- SAST просканировал 13 целей: semgrep берёт только отслеживаемые git файлы,
  а репозиторий на момент прогона был пуст. Полный прогон — после первого коммита.

**Решения фазы**

- Vite SPA вместо Next.js BFF — заменяемость важнее SSR ([[ADR-002]]).
- `pg_uuidv7` не собирается из исходников; UUIDv7 генерируется приложением +
  дублирующая SQL-функция ([[ADR-004]]).
- **По требованию владельца в `RULES.md` внесён обязательный пофазный гейт
  сетевой безопасности (§3.2)** с 10 проверками и требованием немедленного
  исправления находок. Реализован инструментом `scripts/network-audit.mjs`,
  который проверяет фактическое состояние (реальные привязки портов, реальные
  заголовки ответа, реальное поведение CORS), а не намерение в конфиге.
- Порт core перенесён 4000 → **4300**: 4000 занят посторонним проектом на этой
  машине, причём слушающим на всех интерфейсах.
